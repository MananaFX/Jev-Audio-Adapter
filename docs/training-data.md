# 数据使用与范围

## 训练

最新训练方法见 [架构与训练设置](architecture.md)。两个阶段使用同一公开混合数据划分：训练集 39,412 条，验证集 2,773 条。

训练与验证来源为 NSynth、CochlScene、MELD、NonSpeech7k、ClothoAQA、MInDS-14（全部 14 个 locale）和 ESC-50。各来源经筛选后的实际条数尚未逐项披露，不将抽样上限当成保留数量。

MMAU、MMSU、MMAR 仅用于评测，不纳入本轮 train/dev。训练与测试涉及同名数据集时仍须区分 split，不能把测试题直接作为训练样本。本仓库不提供私人数据或逐样本清单。

当前文档不足以构成完整可重现的训练 manifest。各训练来源的固定版本、划分与再分发许可需在发布实现或数据前补齐，不能把测试集列表直接视为训练数据来源。
