# 评测协议

## 数据与预处理

- 七个公共测试集共 22,118 题，包含 21,727 份唯一音频；保留题目 ID、问题、选项内容及顺序、标签和评分字段。
- 相同音频对应多个不同问题时，保留各题，不按音频去重。
- 音频统一为 mono 16 kHz PCM16 WAV；长音频完整保留，不按 30 秒截断。89 条音频超过 30 秒，最长 304.96 秒。
- 数据完整性与模型资源在推理前检查；已完成预测的唯一题目 ID、分母和正确数在汇总时再次核验。

## 评分与完整性

多选分类使用 Accuracy，分母为对应完整测试集题数。完整完成的测试集才报告最终单项成绩；未完成样本不当作零分，部分进度不冒充完整集结果。不同数据版本、预处理、候选顺序或评分方式的结果不得直接作为同协议排名。

本轮已完整完成 CochlScene、NSynth、NonSpeech7k、MELD、MMSU。MMAR 完成 68 / 1,000，MMAU 完成 0 / 1,000。总体为 20,186 / 22,118，执行错误为 0，受计算预算限制停止。完整单项指标见 [主页](../README.md)。

## checkpoint 与选择说明

本轮报告训练第 2,250 步 checkpoint 的结果。训练结束 checkpoint 尚未评测，不进行不完整的跨 checkpoint 比较。

checkpoint 的选择允许参考测试集结果，因此标记为 **test-selected; no independent test**，不作为独立盲测结果。当前未据七项完整结果选出新的最佳 checkpoint。

仓库仅发布方法与汇总结果，不发布原始音频、模型权重、逐样本预测或私人工作环境信息。
